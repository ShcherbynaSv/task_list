**Todo List**

A simple and intuitive task management application built with Django.

**Features**
- Create, update, and delete tasks
- Mark tasks as completed or undo completion
- Set optional deadlines
- Organize tasks with multiple tags
- Create, update, and delete tags
- Sort tasks by completion status and creation date
- Sidebar navigation available across all pages

**Tech Stack**
Python
Django
SQLite
HTML / CSS

**Setup**
git clone <repository-url>
cd <project-directory>
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

Open http://127.0.0.1:8000/ in your browser.
